# Global EV Market Strategy & Analysis 🚗⚡

## Project Overview

**Global EV Market Strategy & Analysis** is a data analytics and visualization project developed using Tableau. The project explores electric vehicle (EV) market data to understand sales performance, manufacturer trends, regional distribution, vehicle categories, pricing patterns, and battery performance.

The objective is to transform raw data into interactive dashboards and story-based visualizations that help users explore market patterns and derive meaningful business insights.

## Project Objectives

- Analyze electric vehicle sales performance across model years.
- Identify leading EV manufacturers based on sales.
- Explore EV distribution across regions and vehicle categories.
- Compare battery capacity with driving range.
- Understand EV pricing patterns across categories.
- Examine battery technology and customer ratings.
- Present findings through an interactive Tableau dashboard and story.

## Tools & Technologies

- **Tableau Public** — Data visualization, dashboards, and storytelling
- **CSV** — Dataset format
- **Data Analytics** — Exploratory analysis and visual interpretation
- **GitHub** — Project documentation and version control

## Dashboard Highlights

The project includes key performance indicators (KPIs) and multiple visualizations designed to explore different aspects of the EV market.

### Key Performance Indicators

- Total EV Records / Models
- Annual Sales
- Average EV Price
- Average Battery Capacity
- Average Driving Range
- Average Customer Rating

### Visualizations

| Visualization | Purpose |
|---|---|
| Sales Trend | Explore annual EV sales patterns |
| Top 10 Manufacturers | Compare leading manufacturers by sales |
| Region vs. Category | Examine regional and category-level patterns |
| Manufacturer Treemap | Compare manufacturers and categories visually |
| Category-wise Sales | Analyze sales across EV categories |
| EV Distribution Map | Explore geographic distribution |
| Battery Capacity vs. Range | Investigate the relationship between capacity and driving range |
| Battery Technology Comparison | Compare battery technology categories |
| Price Distribution | Examine price variations across EV categories |

## Interactive Features

The dashboard and story are designed to support interactive exploration through available filters and dashboard interactions. These features help users investigate selected regions, categories, manufacturers, and other relevant dimensions.

## Project Workflow

1. **Data Understanding** — Review the available EV dataset and identify relevant fields.
2. **Data Preparation** — Prepare the data for analysis and visualization.
3. **Exploratory Analysis** — Examine sales, manufacturers, regions, pricing, and battery-related attributes.
4. **Visualization Development** — Build charts and supporting worksheets in Tableau.
5. **Dashboard Development** — Combine relevant visualizations and KPI cards into an interactive dashboard.
6. **Story Development** — Organize visualizations into a story to communicate findings.
7. **Documentation** — Prepare project documentation and organize deliverables for GitHub.
